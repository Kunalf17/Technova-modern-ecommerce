# TechNova enhanced project

## Files to copy
- Replace the five existing HTML files with the versions in this folder.
- Copy `js/script.js` into your project's `js` folder.
- Copy `css/interactive.css` into your project's `css` folder.
- Keep your original `css/style.css` exactly as it is.

## Features added
- Persistent shopping cart using localStorage
- Cart quantity controls and subtotal
- Wishlist saved in localStorage
- Product search, category filter and sorting on products.html
- Mobile navigation toggle
- Contact form front-end validation
- Toast notifications and scroll reveal effects

## Important
This is a front-end college-project demo. It does not process real payments or send contact-form messages. Product/cart data is stored in the visitor's browser.

## Run locally
Open the project through VS Code Live Server. GitHub Pages can host the static HTML/CSS/JS files.
